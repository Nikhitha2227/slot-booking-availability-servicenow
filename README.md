# Slot Booking and Availability Management System

A ServiceNow application developed to manage slot availability and booking requests.

## Features

- Manage available slots
- Create and manage booking requests
- Track booking status
- Handle booking cancellations
- Prevent duplicate bookings

## ServiceNow Configuration

### Tables

Created custom Booking and Slot tables to manage booking details and slot availability.

### Client Scripts

Used Client Scripts for booking date validation and selecting available slots based on the selected date.

### Business Rules

Used Business Rules to prevent duplicate bookings and update slot availability when a booking is confirmed or cancelled.

### Flow Designer

Used Flow Designer to send notifications when the booking status changes.

### UI Builder

Created a dashboard to monitor bookings and slot availability.

## Technologies

- ServiceNow
- Client Scripts
- Business Rules
- Flow Designer
- UI Builder
