# Client Scripts

Client Scripts are used to validate booking information and control form behavior on the client side.

## Booking Date Validation

A Client Script is used to validate the booking date entered by the user.

The script checks the selected date before allowing the booking information to be submitted.

This helps prevent invalid booking dates from being entered.

## Available Slot Selection

A Client Script is used to control slot selection based on the selected booking date.

After a booking date is selected, the user can select an available slot for that date.

This helps the user choose only the slots that are available for booking.
